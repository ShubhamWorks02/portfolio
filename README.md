# Shubham Bhatt Portfolio

Two static portfolio directions for Shubham Bhatt, focused on native Android + iOS engineering, BLE wearable systems, real-time communication, and open source work.

## Run locally

```bash
python3 -m http.server 5173
```

Then open:

```text
http://localhost:5173/
```

## Versions

- V1 Editorial / Refined: `http://localhost:5173/`
- V2 Mobile-Native: `http://localhost:5173/mobile-native.html`

## Notes

- Both pages are intentionally dependency-light: single HTML files with scoped CSS and vanilla JavaScript.
- Animations use Intersection Observer and respect `prefers-reduced-motion`.
- Open source PR titles/statuses were checked against the public GitHub API on 2026-05-30.
